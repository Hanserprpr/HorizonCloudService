# 🎯 Mock数据演示指南

## 🚀 快速开始

系统设置页面现在使用Mock数据，你可以完整体验所有功能而无需后端服务！

### 访问方式

1. **启动开发服务器**:
   ```bash
   npm run dev
   ```

2. **访问应用**: http://localhost:3001

3. **登录系统**:
   - 用户名: `admin`
   - 密码: `admin123`

4. **进入系统设置**:
   - 点击左侧菜单 "系统设置"
   - 或直接访问: http://localhost:3001/settings

## 🎭 Mock数据特色

### 智能交互
- **真实延迟**: 所有操作都有模拟网络延迟(500-3000ms)
- **状态变化**: 服务重启后状态会真实改变
- **动态数据**: 内存使用、运行时间等数据会动态更新

- **存储连接测试**: 输入无效配置会显示错误信息

- **缓存清理**: 显示清理的文件大小信息
- **设置保存**: 所有设置都会持久化到Mock数据中

### 企业级UI体验
- **加载状态**: 所有异步操作都有Loading状态
- **成功反馈**: 操作成功后显示Toast消息

- **确认对话框**: 危险操作(重启服务、清理缓存)需要确认

## 📝 开发说明

当后端服务完成后，只需要将:
```typescript
// 从
import { useSystemSettings } from '@hooks/useSettingsMock';

// 改为
import { useSystemSettings } from '@hooks/useSettings';
```

Mock数据服务完全遵循真实API接口设计，确保前后端无缝对接。
